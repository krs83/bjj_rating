**🥋 BJJ Rating**

Система рейтинга спортсменов по бразильскому джиу-джитсу (BJJ). Веб-приложение с публичным рейтингом, админ-панелью и REST API.

**📋 Описание**

Проект представляет собой полноценное веб-приложение для ведения рейтинга спортсменов BJJ:

Публичный фронтенд — рейтинг топ-спортсменов, поиск, карточки атлетов с историей турниров

Админ-панель (SQLAdmin) — управление спортсменами, турнирами, пользователями

REST API — CRUD-операции для интеграций, авторизация через JWT

Миграции БД — управление схемой через Alembic

**🛠 Стек технологий**

**Backend**

- Python 3.12
- FastAPI — веб-фреймворк
- SQLModel + SQLAlchemy 2.0 — ORM
- PostgreSQL + asyncpg — база данных
- Alembic — миграции
- Pydantic v2 — валидация данных
- Аутентификация
- JWT (PyJWT)
- Passlib (pbkdf2_sha256)

**Frontend**

- Jinja2 — шаблоны
- HTMX — динамические запросы без SPA
- Bootstrap 5 — стилизация

**Админка**

- SQLAdmin

**Инфраструктура**

- Docker + Docker Compose
- Traefik — reverse proxy + SSL (Let's Encrypt)

**Инструменты**

- pytest — тестирование
- ruff, mypy — линтинг и типизация
- uvicorn — ASGI-сервер
